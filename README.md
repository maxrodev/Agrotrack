# AgroTrack

Plataforma web para gestionar parcelas, cultivos, monitoreo del suelo y alertas climáticas. Proyecto universitario desarrollado en equipo con arquitectura DDD (Domain-Driven Design).

> Este repositorio es un resumen del proyecto. **Todo el código está en la organización:** [github.com/AgroTrack-Project](https://github.com/AgroTrack-Project)

## Mi aporte

Participé en el **bounded context de clima**, en backend y frontend, con el consumo de una API externa bajo DDD.

## Tecnologías

| Capa | Tecnologías |
|---|---|
| Backend | Java, Spring Boot, API REST, Swagger |
| Base de datos | MySQL |
| Frontend | Angular, TypeScript |
| Arquitectura | Domain-Driven Design (DDD) |
